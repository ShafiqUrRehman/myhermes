# Privacy Policy - MyHermesApp

Last updated: 26 September 2026

MyHermesApp is a personal-use application. Its only user is its owner.

## Data accessed

When authorized, the app accesses Google account data (such as Gmail, Google Calendar and Google Drive) belonging to the owner's own account, only to carry out tasks the owner requests through a self-hosted assistant.

## How data is used and stored

Data is processed on the owner's own server, and OAuth tokens are stored only on that server. Data is not sold, not shared with third parties, and not used for advertising. Content may be sent to the AI model provider configured by the owner, solely to complete the task the owner requested.

## Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions
